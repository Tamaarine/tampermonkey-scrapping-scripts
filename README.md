# TamperMonkey Scripts
This is a repository that is storing all of my TamperMonkey scripts.

It is just a bunch of scripts that I found useful for scrapping images,
videos, etc...

# vsco.js
This script adds a Download button to VSCO and clicking on it makes it so
that it scrolls down and render all of the images to be able to download
all of them into the browser's download folder.
